# Popcorn 性能审计

基线为 `c5ad6c4`。本轮使用同一台 Ryzen 7 9700X、Radeon RX 7900 XT 的 Windows 主机和 Playwright Chromium。WebGL 报告 ANGLE D3D11，GPU 帧时来自异步计时查询。五个场景的顺序为灶台、厨房、电影院、小城、地球。

## 采样口径

- 1440p 稳态覆盖五个场景与四个画质档。每个已解锁设备 120 台，存档状态含所有升级和 12 种口味，累计产量固定在 97% 进度，按住连爆并每秒再点 10 次，狂热持续，支持大炮的场景每 2 秒打一发绿区炮。待预加载完成后采样 6 秒。飞行中的收益仍能改变画面上的堆高，固定堆高另行采样。
- 1080p 低档使用相同压力，CDP 主线程降速 4 倍。SwiftShader 另作软件渲染压力样本。两者分别提供 CPU 和软件 GPU 数据，实际低端硬件仍需真机覆盖。
- 4K 极高档覆盖四次场景突破和地球结局。冷切场会在目标场景可能仍在构建时触发，测试固定一次突破，避免极限模拟产量在同一镜头里连跳多个场景。
- 限帧测试的卡顿计数使用超过 25 ms 的帧间隔，另记超过 50 ms 的帧。JS CPU 时间含提交 WebGL 命令的时间，GPU 查询只包围 Stage 渲染，浏览器样式、合成和部分后台构建单独用跟踪观察。不限帧模式用读回等待 GPU，衡量整条同步路径的吞吐。
- Draw Call 和三角形预算由 `budget` 逐帧统计，稳态矩阵的三角形为窗口结束时的样本。首访使用空缓存、10 Mbps、40 ms 的生产构建。内存区分 GC 后的 JS 堆、Three.js 资源数与浏览器 GPU 进程的 WDDM 显存计数。

## 定位与实现

| 路径 | 证据与处理 |
| --- | --- |
| 堆积实例 | 电影院极高档的堆面一次绘制提交约 266 万三角形。按原顺序压紧实例，只有双线性高度采样脚印涉及的所有格子都未被填充、顶点着色器必定剔除的粒子才跳过提交。边界保留额外格子，原有 GPU 剔除、顶点细节、阴影和弹簧位移继续执行。退休场景释放堆面实例缓冲，保留远景高度场。 |
| 高度场和造型 | CPU 采样指向锅形更新的半径、曲线和溢出计算。半径在建场时缓存，按填充高度只计算一次公共参数。生成爆米花模型时跳过对结果贡献为零的球冠和噪声项。 |
| 光影与后处理 | 在确认格子可能跨越陡坡之后才取样精细高度。环境遮蔽的两张目标采用同一精度的单通道。Bloom 在已有 mip 目标上按原权重混合，省去一组 HDR 目标和一次基底纹理读取。全屏通道覆盖所有像素，借此省去清屏。光照采样数、MSAA、景深、反射和各档内部渲染分辨率沿用原设置。 |
| 机器、粒子和切场 | 铺完的轨道复用已提交的矩阵，飞行粒子只上传当前实例范围。着色器与缓存用同格式的 4×4 阴影目标预热，正常渲染和探针继续用全分辨率。提前突破时，下一场景可在蓄压镜头中继续预加载，切入镜头前补齐剩余步骤。 |
| 首访 | 字体加载与存储读取重叠，造型生成跳过确定为零的计算。字体到齐后照常构建标牌和场景，存档按原迁移、恢复流程加载。 |

单独的 GPU 实例姿态预处理曾作为实验。它多了一次绘制和三张纹理，电影院初测没有收益，因此已从实现中移除。

## 软件渲染压力

在 SwiftShader 上运行 720p 低档电影院满载，FPS 从 1.6 升至 1.7，GPU 查询均值 639.88 → 603.92 ms。每种构建仅得到约 10 帧，这组数字用于量化纯软件路径的负担。现代入门或集成 GPU 的实际体验需要直接测量。

## 冷启动与 GC

同批次各三次生产构建首访。中位首绘 396 → 388 ms，标题可操作 2,850 → 2,632 ms，下载仍为约 0.46 MiB。标题范围分别为 2,756–2,975 ms 和 2,619–2,776 ms，首次基线批次另录得 2,657–2,800 ms。六次配对采样的开局 10 秒均无超过 50 ms 的帧，P99 均为 16.8 ms。生产入口 gzip 体积为 349.07 → 349.64 kB。

电影院 1440p 极高档的 6 秒 CDP 跟踪中，两版各有 9 次游戏主线程 GC。累计 3.5 → 6.8 ms，最长 0.57 → 2.17 ms，均无超过 5 ms 的 GC。由堆计数器估算的分配速率下界 19.90 → 19.55 MiB/s。该窗口同时开启 CPU 采样，游戏帧 CPU 均值 2.70 → 2.13 ms，P99 5.8 → 3.4 ms。

V8 自耗时采样中，锅形函数在 6 秒窗口内由约 48 ms 降至约 8 ms，实例压紧约 1 ms。采样值用于定位耗时来源，逐帧统计用于衡量用户侧变化。

## 数值与画面核验

程序生成的 30 个粒子模型在位置、法线、内核位置、内核法线、着色属性上逐字节一致。五个场景的堆形计算共对比 172,980 个位置和填充组合，最大数值差为 0。

43 个 WebGL 画面对比覆盖五场景、四档画质、近景粒子和演出。基线与优化版之间所有像素的最大色阶差为 1/255。各版内部重复拍摄时，42 张逐字节复现，两版各自的标题样张有一次哈希差异。标题的跨版本画面也保持在一个色阶以内。

极高档 `npm run budget` 的五场景和切场检查通过。峰值 Draw Call 为 113 → 113，峰值三角形为 9,667,763 → 7,662,385，减少 20.7%。

`npm run check` 的 177 个用例通过，经济平衡验收通过，音频检查通过（结局满载真峰值 −3.1 dBFS）。自动通关走完 82.3 分钟模拟流程，展示制作人员名单，零报错。
