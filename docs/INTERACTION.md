# 界面与建模规范

本文件是《砰！爆米花失控了》界面外观、交互手感和模型精细度的统一标准。新增或修改任何界面、按钮、弹窗、模型时，都以这里为准；需要偏离时，先改这里，再改代码。

参照对象是 iOS 等成熟产品的做法：按下立刻有反应，松开才执行；动画随时可打断；退场比入场更快更安静；每个状态变化都有对应的画面、声音和触感。风格保持游戏自己的复古糖果色和票根元素。

---

## 1. 视觉规范

全部写成 CSS 变量，定义在 `src/ui/base.css` 的 `:root`。组件样式只引用变量，不写裸数值。界面统一用 `rem`，1rem 在 1920×1080 下为 10px，随窗口等比缩放。

### 1.1 圆角

| 变量 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 0.8rem | 角标、小芯片 |
| `--r-s` | 1.2rem | 小按钮、输入框、分段控件内的滑块 |
| `--r-m` | 1.8rem | 票根、卡片、列表分组 |
| `--r-l` | 2.8rem | 弹窗、商店面板、大面板 |
| `--r-pill` | 999rem | 主要按钮、开关、胶囊提示 |

- 嵌套元素同心：内圆角 = 外圆角 − 两者之间的内边距，最小不低于 `--r-xs`。
- 支持时用 `corner-shape: squircle` 做连续曲率圆角，不支持时退回普通圆角。

### 1.2 间距

`--s-1` 到 `--s-7` 依次为 0.4 / 0.8 / 1.2 / 1.6 / 2.4 / 3.2 / 4.8 rem。

- 屏幕安全边距 `--edge` = 2.4rem：任何界面元素离窗口边缘不少于这个距离，不能被裁切。
- 同组元素间距用 `--s-2`～`--s-3`，组与组之间用 `--s-5`～`--s-6`。
- 弹窗内边距统一 `--s-6`。

### 1.3 字号

| 级别 | 变量 | 字号 / 行高 | 用途 |
|---|---|---|---|
| 大标题 | `--t-display` | 6.4 / 1.05 | 标题页、场景标题牌 |
| 标题 | `--t-title` | 3.6 / 1.15 | 弹窗标题 |
| 小标题 | `--t-headline` | 2.4 / 1.25 | 票根名称、分组标题 |
| 正文 | `--t-body` | 2.0 / 1.4 | 说明、菜单项 |
| 说明 | `--t-caption` | 1.6 / 1.35 | 次要信息、角标外的小字 |

- 标题、名称、按钮和大字用快乐体；小号说明文字（票根说明、提示正文、成就说明、分组标题、按键说明等）用系统黑体 `--font-text`。依据：1280×720 下两种字体的对比截图，快乐体在 10px 左右笔画发糊，系统黑体清楚得多。
- 数字统一用 Fredoka，`font-variant-numeric: tabular-nums`，变化时宽度不跳。
- 中文长句加 `text-wrap: pretty`，不出现孤字换行。
- 正文最小 1.6rem；1280×720 下仍要清楚可读。

### 1.4 颜色

在现有糖果色上建立用途变量：`--surface`（底面）、`--surface-raised`（浮起面）、`--text`、`--text-2`（次文字）、`--accent`、`--positive`、`--negative`、`--disabled`。

- 小字与背景对比度不低于 4.5:1，大字不低于 3:1。
- 买不起、未解锁等状态靠颜色和形状两种方式同时表达。

### 1.5 层级与材质

| 层级 | 用途 | 投影 |
|---|---|---|
| 0 | 贴在面板上的元素 | 无 |
| 1 | 票根、卡片、按钮 | 近距离柔和投影 |
| 2 | 商店、计数器等常驻面板 | 中距离投影加一层环境投影 |
| 3 | 弹窗、菜单 | 远距离大投影，背景模糊变暗 |

- 投影带暖色，多层叠加，不用纯黑硬投影。
- 浮在 3D 画面上的面板用毛玻璃：背景模糊、提亮、略增饱和度，边缘一道细高光。
- 不用粗边框；需要分隔时用细线或明暗差。

### 1.6 图标

统一线宽和 48 网格，视觉居中（三角形等不对称图形按重心校正），同一行的图标视觉大小一致。

### 1.7 比例与布局

- 弹窗宽度三档：窄 48rem、中 64rem、宽 88rem，高度不超过窗口的 84%，超出时内部滚动。
- 主要按钮高 6rem，次要按钮高 5rem；同一按钮组宽度一致。
- 主界面对齐到同一套网格：左上角按钮、顶部计数器、右侧商店、底部阶段条、左下压力表，全部在安全边距之内。
- 商店面板宽度占窗口 22%～30%。

## 2. 交互规范

### 2.1 按压规则（`src/ui/press.ts`）

- 按下的当帧显示按下状态，并捕获指针。
- 在按钮范围内松开才执行；移出按钮或拖动超过约 10 像素即取消，触屏可以正常滚动列表。
- 例外：点锅和按住大炮按下即生效，保证游戏操作零延迟。
- 票根按住约 0.4 秒后开始连续购买，速度逐渐加快，每次都有轻触感和音效。
- 回车和空格与点按一致；焦点环清楚可见。
- 所有可点区域不小于 44 像素（4.4rem 在 1080p 下）。

### 2.2 动效参数（`src/ui/motion.ts`）

弹簧按 iOS 的方式定义（响应时间、阻尼比），由 `spring()` 预先算成 CSS `linear()` 缓动，交给浏览器执行。`setMotion()` 把同一组曲线写成 CSS 变量 `--ease-<名称>` 和 `--dur-<名称>`，CSS 过渡和脚本动画因此完全一致。只动位置、缩放和透明度；例外是弹窗卡片和商店卡片换页时的高度过渡，以及商店场景分组的折叠展开，都只影响卡片自身。

时长是弹簧完全静止（误差小于 0.5%）的时间，肉眼可见的运动大约在一半时长内完成。

| 动作 | 参数 |
|---|---|
| 按下 | 缩放 0.96（大卡片 0.98，小图标 0.90，列表行不缩放而是整行变暗），略微变暗，70ms |
| 松开 | 弹簧：响应 0.3 秒，阻尼 0.7，约 430ms，轻微过冲；可从任意中间状态接上 |
| 出现 | 弹簧：响应 0.3 秒，阻尼 0.82，约 400ms；从 0.94 倍缩放加淡入，移动约 8 像素 |
| 消失 | 170ms 缓入，比出现更快 |
| 切换 | 指示器和卡片高度：弹簧，响应 0.3 秒，阻尼 0.86，约 350ms；内容按方向交叉淡入 190ms |
| 列表 | 增删和重排都用 FLIP，其他项平滑移到新位置；新项以"出现"浮入 |
| 换页 | 新页从右侧推入，返回从左侧滑回，卡片高度同步过渡 |
| 买不起 | 左右摇头 300ms，叠加在回弹之上，不打断回弹 |

减少动态效果时：位移和缩放全部去掉，只保留淡入淡出；提示条的上下浮动和狂热跳动停止。

### 2.3 交互状态

| 状态 | 表现 |
|---|---|
| 常态 | 静止 |
| 悬停（桌面） | 微微提亮；列表行和分段项加深一点底色 |
| 按下 | 缩小、变暗、阴影收紧 |
| 松开 | 弹簧回弹 |
| 买不起 | 按下时凹陷变灰，轻轻摇头，低沉"嗒"声，错误触感 |
| 刚变成可买 | 扫过一次光泽，只扫一次 |
| 选中 | 指示器停在该项 |
| 键盘焦点 | 焦点环 |
| 处理中 | 变淡、光标显示等待，期间不能重复触发（导入存档） |

### 2.4 音效与触感

| 事件 | 音效 | 触感（支持振动的设备） |
|---|---|---|
| 按下 | 轻"嗒" | 约 8ms |
| 松开执行 | 轻"啵" | 无 |
| 切换、分段控件 | "咔哒" | 约 8ms |
| 开关 | "喀" | 约 10ms |
| 滑块刻度 | "滴答"，音高随数值变化 | 每 10% 一次约 5ms |
| 弹窗出现 / 关闭 | 柔和"嗖" / 更短的"嗖" | 无 |
| 成功（购买、确认） | 明亮短音 | 短、停、短 |
| 失败（买不起） | 低沉"嗒" | 两次稍重 |
| 里程碑 | 华丽短音 | 更重 |

- 每次音高随机浮动约 ±3%，连续触发有频率上限。
- 设置里有"界面音效"音量和"触感反馈"开关。
- iOS Safari 和桌面没有振动，用动效和音效补足。

## 4. 建模精细度标准

### 4.1 三级细节

1. **剪影：** 缩略图和灰度图里一眼认得出是什么。
2. **部件：** 活动部件、把手、门、轮子、管线等结构清楚。
3. **细节：** 螺丝、缝线、标签、刻度、电线、磨损和贴纸；数量服从主次，不平均撒。

### 4.2 造型

- 所有硬边都有倒角，`P.box` 的圆角不小于短边的 4%。
- 曲面分段按尺寸给：在首次购买特写和拍照模式的最近距离下看不出折面。
- 同一场景里，木纹、砖、布料等图案的尺度一致。
- 接缝和凹槽有烘焙遮蔽，零件之间不悬空、不穿插。
- 材质分得清：金属、烤漆、木、布、橡胶、玻璃各自有不同的光泽和纹理。
- 表面图案共 13 种，用 `Pattern` 选择，小数部分调尺度。新增的 6 种各有固定用途：滚花（`Knurl`）用于旋钮、握把；冲孔板（`Perforated`）用于通风口、格栅；花纹钢板（`Tread`）用于踏板、车厢地板、坡道；釉面陶瓷（`Glaze`）用于碗和瓷器；皮革（`Leather`）用于座垫、握把包皮；纸（`Paper`）用于标签、价签、告示、乐谱。
- 细到一个像素以下的凹凸会闪，所以每种图案在半个周期一像素之前就淡出，强光下的亮面漆不会起"闪粉"。

### 4.3 动作

- 工作循环有预备、动作、回弹和跟随，节奏与音效对齐。
- 入场、档位变身都有完整的起止状态，结束状态等于下一个状态的开始。
- 档位外观：25 台是各设备自己的装饰件；50 台别上银色奖章，100 台换成金色奖章（台风例外，它的金色风眼就是 100 台外观）。跨过 25、50、100 台时，场上的每一台依次跳起、转一圈、放大回弹，周围炸开亮片，奖章弹着别上去；减少动态效果时只有亮片和直接换装。
- 沿路径行驶的设备（小火车）：第一台到达时轨道一节节铺出来，车头停靠约 2.6 秒让特写拍到，再缓缓加速开走；后面每买一台多挂一节车厢。

### 4.4 验收方法

- `node tools/turntable.ts` 四面图逐张检查。设备常靠墙或挨着爆米花堆，所以四张都从正面扇形取景。
- 特写距离各出一张，对照本节逐条检查。
- 原图、灰度图、缩略图三种审查。
- 预算以 `tools/budget.ts` 为准。

## 5. 场景叙事与光影

### 5.1 进度叙事

- 每个场景有三个样子：开始、中段、末段。灯光和调色写在场景规格的 `story` 里（中段 `mid`、末段 `late`），镜头按本场景的进度在三者之间过渡：进度 0.12～0.5 走到中段，0.55～0.92 走到末段。
- 布景通过 `progress(u)` 钩子跟着走：窗外天空（`materials/sky.ts`，窗玻璃和天穹共用一种着色器）、灯、月亮、道具动作。
- 读档时一步到位（`instant`），正常游玩时逐渐过渡。场景被下一个场景吞进去变成小摆件时，停在末段的样子。

| 场景 | 开始 | 中段 | 末段 |
|---|---|---|---|
| 灶台 | 黄昏，窗外粉橙色带云 | 蓝调时刻，月亮露头，置物架下的灯条亮起 | 入夜，月亮升高、越抖越频繁，水壶冒气 |
| 厨房 | 午后阳光，吊灯关着 | 日落，吊灯和壁灯依次亮起 | 傍晚，月亮和星星，柜下灯带亮起，冰箱门虚掩透光，厨师打瞌睡 |

### 5.2 灯组

- 窗户、灯泡、霓虹等发光件属于"灯组"，每个场景 8 组（`lightGroup(scene, index)`），由场景的 `LightBank` 按进度或按需开关。
- 灯组关闭时是深色、发亮的玻璃；`lightKeepsPaint` 的部件（钟面、灯罩）关闭时保留原色，只是不再发光。
- 霓虹打开时会闪几下再亮稳，灯泡则是渐亮；减少动态效果时都改为渐亮。
- 灯组只占一个全局数组，不增加任何绘制次数。

### 5.3 装修与玩具小人

- 每个场景的装修、玩具小人和会动的道具合成一个部件骨架（`scenes/pieces.ts` 的 `SetPieces`），本体、描边、阴影各一次绘制。
- 买下装修时，装修以回弹弹出并炸开亮片；读档或减少动态效果时直接出现。
- 玩具小人统一由 `toyFigure` 组成：身体、头、两只手臂四个部件，高 1 个单位，按场景缩放。成群出现的小人（小城行人）用 `figureGeometry` 合成一个网格画实例，分段更少。

### 5.4 光影

- **软阴影（高、极高画质）：** 投影体同时把深度写进一张颜色图，先在周围找遮挡物估算半影宽度，再按宽度过滤：贴地处清楚，离得越远越柔。找不到遮挡物时退回固定宽度。
- **遮蔽：** 半分辨率水平角遮蔽（GTAO 近似，2 个方向、每侧 5 步），两遍按深度模糊，合成时按深度挑选四个邻近采样放大，轮廓不渗黑边。
- **事件光：** 2 盏短时灯给开炮、金色玉米、连击和突破；狂热时堆上方再加 1 盏随音乐节拍跳动的暖光。减少动态效果时事件光减半、狂热灯不跳。
- **狂热：** 整体调色变暖变亮，泛光随节拍起伏，爆米花表面闪糖粒。
- **移轴焦带：** 只在拉远的全景里生效，画面上下离开中间一条带、且不在焦距上的东西更早变虚；在焦距上的设备保持清楚。强度每个场景单独设（`tiltShift`），小城最强。
- 灯光上限 16 盏：场景自己的灯按画质限量（低 3、中 6、高和极高 12），事件光另算。关着的灯不占名额。
- **环境探针（中画质起，`core/probe.ts`）：** 每个场景在后台构建的最后，从容器上方拍下布景（不含设备、堆和粒子），开始、中段、末段三种灯光各拍一张 256 的立方体图，预滤成粗糙度分级。搪瓷、铬、清漆和玻璃按自己的粗糙度反射这间屋子；柔和补光也有一部分取自它（场景规格 `envDiffuse`，默认 0.6；地球只用 0.15，因为一个拍摄点照顾不到球体的背面）。按故事进度在相邻两张之间混合，突破爬升时从旧场景的末段过渡到新场景的开始。拍摄时探针本身是关着的，不会拍进旧的探针。游玩中不再重拍，不占绘制次数；后台每帧只拍一面。低画质仍用三色渐变。
- **堆的反光：** 爆米花是画面里最亮的东西，堆旁边朝向它的面会被照得暖亮。颜色取当前口味的奶油色，乘以当时的日光，强度随堆的大小增长（场景规格 `bounce`，默认 0.3）。
- **光束（高、极高画质）：** 半分辨率、一次绘制：亮部沿屏幕上光源的方向拉出光线，前面挡着的东西会切出光缝。只用在有遮挡的光源上：灶台和厨房的窗、电影院的银幕。小城和地球的天空太大，拉出来是一整片雾，所以不用。
- **高光抗锯齿：** 法线在一个像素内转得越多，高光就越宽，细小倒角在 1080p 和 4K 下都不闪。
